# UI 交互与视觉验收说明

## 设计原则

- 视觉气质：温暖、克制、可信，避免“赛博 AI 仪表盘”和模板化卡片堆叠。
- 信息结构：始终让用户知道现在处于经历、探索、生成还是报告阶段。
- 结论表达：职业方向是需要验证的假设，不是人格标签或命运判词。
- 证据表达：不同来源使用固定徽标和文字，不能只靠颜色区分。
- 品牌标识：统一使用黑色圆形、白色罗盘指针的极简 Logo；页头使用 SVG，浏览器/App 图标保持同一轮廓，不再使用“北”字旧图标。
- 移动优先：主要操作按钮、选项和弹窗在窄屏下堆叠为单列，正文不依赖横向滚动。

## 关键状态

1. 首页：价值主张、三导师罗盘图、产品原则和核心 CTA。
2. 画像：7 组输入，必填校验、字数提示、隐私提醒、标签多选。
3. 提问：每次只展示一题；选择后才可继续；前三题后动态选择第 4 题。
4. 生成：用阶段文案解释 AI 正在做什么；失败显示可操作重试，不展示底层堆栈。
5. 报告：首条路径默认展开，其他路径可按需展开；来源与全局限制独立成区。
6. 贡献：先授权，再生成可编辑草稿；五项确认完成前禁止进入待审核。
7. 降级：Mock / 缓存结果有明显提示，不与实时联网结果混淆；个性化题目降级时用一句话说明安全原因（如“AI 响应超时”），并继续提供可用的通用探索题。

## 响应式断点检查

- `> 1040px`：首页与输入页使用双栏结构，报告内容保持适合阅读的最大宽度。
- `720—1040px`：主要网格缩减，保留清晰层级。
- `< 720px`：所有双栏改为单列；页头、步骤、操作栏、路径摘要与弹窗按钮适配触摸操作。
- `< 460px`：减小外边距和标题字号；标签和来源元信息允许自然换行。
